Chronoscape renderer benchmark

Compares the saved pre-ui-redesign Canvas renderer with the current renderer at the same 1000 × 640 CSS pixels, projection, historical data, camera coordinates, and raster density. Both use dark colors, labels, and cities; modern borders are off.

Measures main-thread preparation + drawing CPU. Network, JSON loading, worker startup, animation-frame waiting, browser paint, and GPU completion are excluded. This is not a load-time or frame-rate benchmark. Product controls are excluded from both. Each pair alternates execution order; two animation frames separate samples.

Measurement details and raw results

Year tests retain each implementation’s real temporal caches. “First pass” uses 24 distinct years; “revisit” repeats those years in reverse. Camera tests hold the latest common year constant and use 40 distinct pan/zoom views. Baseline projection fit and clipping are aligned with the redesign for comparable geography; its original rendering and city/label algorithms remain intact. Baseline’s historical bottom-80px label exclusion and global label limits remain part of that renderer. Redesign uses its actual regional labels and caches. The two implementations therefore perform different useful work; inspect draw-only and preparation figures below before interpreting ratios.
