# Current project state

As of the 2026-09-30 ruler expansion, the application contains 13,309 accepted
reigns across 945 of 1,544 atlas identities. There are 599 identities without
accepted rulers and no certified complete roster. The original all-polity
request remains open; source acquisition, scope and historical review continue.

Start with [HANDOVER.md](../HANDOVER.md), the
[ruler continuation record](../workstreams/rulers/chats/2026-09-29__complete-ruler-coverage/handoff.md)
and [all-polity work inventory](../sources/rulers/coverage-audit.json).
The 2026-09-29 documentation handover and its QA remain in their dated workstream.
The checked ruler expansion was committed and pushed as `3b57050`; the remote
`main` branch was verified at that exact commit.

The public data preserve sampled-source, individually checked, approximate,
disputed and incomplete-date records separately. Century-list candidates failed
their source sample and remain discovery-only. Identity metadata do not
independently corroborate dates. Map geometry is unchanged; the ontology remains
unimplemented. Ignored raw source snapshots need a separate transfer for exact
re-extraction, and map sources remain unpinned. A Git push alone does not verify
the GitHub Pages deployment or successor access.
